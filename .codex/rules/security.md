# 安全规范

- 禁止提交 `.env`、JWT 密钥、数据库/Redis 密码、真实 token、私钥或生产连接串；配置从环境变量读取。
- `JWT_SECRET` 在生产环境必须是足够长的随机值；普通业务鉴权必须走 `middleware.JWTAuth()` 和包含 Redis jti 校验的 token 验证流程。
- refresh token 仅用于刷新端点；权限和数据范围中的操作用户 ID 必须来自认证上下文，不能信任前端传入的身份字段。
- 新增私有接口时评估并挂载 `middleware.Perm`；权限码须与数据库按钮菜单及前端权限声明保持一致。
- JSON 请求优先绑定到类型化 DTO 并使用校验 tag；内部错误写日志，对外返回泛化错误，禁止泄漏 SQL、DSN、堆栈和路径。
- 数据查询使用 GORM 参数绑定；任何动态表名、列名、排序字段必须经过白名单校验，禁止直接拼接不可信输入。
- 上传处理必须校验大小、类型、扩展名和目标路径，确保规范化路径仍在上传根目录内。
- 前端不要用 `dangerouslySetInnerHTML` 渲染不可信内容；token 相关变更需同时检查持久化、清除、刷新并发和重试上限。
